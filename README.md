# ⚡ Calculadora de Resistencias PHP

![PHP](https://img.shields.io/badge/PHP-777BB4?style=for-the-badge&logo=php&logoColor=white)
![WSL](https://img.shields.io/badge/WSL-0078D4?style=for-the-badge&logo=windows-terminal&logoColor=white)

Una herramienta web interactiva y educativa diseñada para calcular el valor de resistencias eléctricas basándose en el estándar de código de colores de 4 bandas. 

## 🚀 Características

- **Cálculo Preciso:** Procesa valores, multiplicadores y rangos de tolerancia.
- **Interfaz Reactiva:** Visualización dinámica de la resistencia en tiempo real mediante JavaScript.
- **Lógica de Servidor:** Procesamiento seguro de datos utilizando PHP para el cálculo matemático.
- **Formateo Inteligente:** Resultados con precisión decimal y manejo de unidades (Ω).

## 🛠️ Tecnologías Utilizadas

- **PHP:** Lógica de backend y procesamiento del formulario.
- **HTML5/CSS3:** Estructura semántica y diseño responsivo.
- **JavaScript:** Manipulación del DOM para cambios de color instantáneos.
- **Entorno de desarrollo:** WSL (Windows Subsystem for Linux).
